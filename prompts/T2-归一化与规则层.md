# T2 · 归一化与规则层（L0 + L1）

先读：`AGENTS.md`、`docs/02-解析与交互.md` §1 §4

## 目标

把原始中文输入切成 `[{span, qty, unit}]` 片段。**不查表，不做匹配。**

## 要做

### 1. `packages/core/src/normalize/`

| 文件 | 职责 |
|---|---|
| `fullwidth.ts` | 全角 → 半角（`０-９`、`Ａ-Ｚ`、`ａ-ｚ`、`．`、`／`、`　`） |
| `cnnumber.ts` | 中文数字 → 阿拉伯数字。支持 一二三四五六七八九十两、百、半，以及组合（两百、一百五=150、两百五=250） |
| `index.ts` | 导出 `normalize(raw: string): string`，按 fullwidth → cnnumber → 去多余空白 的顺序 |

**`cnnumber` 自己实现，约 40 行，不要装包。**

### 2. `packages/core/src/parse/rules.ts`

输出类型：

```ts
export interface Segment {
  span: string        // 原文片段（归一化后的）
  raw: string         // 归一化前的原文片段
  qty: number | null  // 数量
  unit: string | null // 单位 id（见 units.yaml）或 null
  start: number
  end: number
}
export function extractSegments(normalized: string): Segment[]
```

**要识别的模式：**

```
<数字><单位><食物>      200g鸡胸 / 200克鸡胸
<食物><数字><单位>      鸡胸200g / 鸡胸 200 克
<食物><数字>            鸡胸200   → unit 默认 'g'
<数字><量词><食物>      两个鸡蛋 / 一碗米饭 / 一拳头米饭 / 半份番茄炒蛋
<食物>                  黄焖鸡   → qty=null, unit=null
```

**单位别名表**（从 `units.yaml` 读，不要写死在代码里）。

**份量修饰倍数**（`normalize/portions.ts`）：

```
半 = 0.5   一 = 1   两 = 2   三 = 3
小 = 0.7   中 = 1   大 = 1.4
```

**约数词**（`左右`、`大概`、`约`、`差不多`）：识别到就抹掉词，但**在 Segment 上加 `approx: true`**。它会传导到输出的 `confidence: 'estimate'`。
