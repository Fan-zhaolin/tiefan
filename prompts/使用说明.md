# 给 Codex 的使用说明

## 怎么用

**一次只给一个 prompt。跑完验收，再给下一个。**

不要一次性把 8 个都丢进去——它会把顺序搞乱，而且你没法定位是哪一步坏的。

```
T0 脚手架        → pnpm lint + pnpm test 通过
T1 数据层        → pnpm validate 通过 + 反向验证两条
T2 归一化与规则  → 单测全绿
T3 字典匹配      → 单测全绿（含三杯鸡）
T4 查表与契约    → 30 条验收 ≥28 通过  ← 核心里程碑
T5 CLI          → 输出格式对齐正确
T6 单文件 Web   → 断网可用、无红线
T7 语料与社区    → 覆盖率 ≥70%
```

## 每个 prompt 的开场白

Codex 需要知道先读什么。建议每轮第一句都带上：

> 先读 `AGENTS.md`，再读 `docs/` 下相关文件，然后执行 `prompts/TX-xxx.md`。

## 三条最容易翻车的地方

### 1. 它会编数据

LLM 写营养数据时**不会报错，只会静默错两倍**。这是本项目最严重的风险。

**防御措施：**
- `AGENTS.md` 铁律 3 已经写了，但你必须亲自抽查
- T1 只让建 5 个文件，就是为了让它没机会批量编
- 看到某个 `kcal` 数值可疑，去 TFDA / USDA 反查一次
- **它如果说"我估算了以下数值"，立刻停，让它改成 `kcal: null`**

### 2. 它会自己加功能

看到"饮食 App"就会想加图表、加目标、加 streak、加提醒。

**防御措施：**
- `AGENTS.md` 铁律 4 和 6 已经写了
- 每轮结束扫一遍 diff，出现 `progress` / `target` / `streak` / `reminder` 这类词就退回
- Web 那轮特别容易加"简单加个进度条"——**进度条就是环，环就是考核**

### 3. 它会偷懒跳过失败用例

为了让测试变绿，它可能给用例加 `skip`。

**防御措施：**
- T4 里已经写了"编数据通过测试 = 项目失败"
- 检查 `acceptance.yaml` 的 `skip` 数量，超过 4 条就重来
- 要求它每轮结束打印通过/跳过/失败三个数

## 给 Codex 的总提示词（复制这段开场）

```
你先读仓库根目录的 AGENTS.md，那是这个项目的铁律，优先级最高。
然后读 docs/01-数据模型.md、docs/02-解析与交互.md、docs/03-架构与边界.md。

三条你必须记住：
1. 不许编造营养数据。查不到就写 kcal: null + note「待录入」，比编一个数字好一万倍。
2. 不许增加文档里没写的功能。想到了写进 docs/BACKLOG.md，不要实现。
3. 不许出现达成率/进度环/红绿/箭头/streak。这是产品红线。

现在执行 prompts/T0-脚手架.md。完成后跑 pnpm lint 和 pnpm test，把结果贴给我。
```

## 每轮验收后的自检清单

- [ ] `pnpm test` 全绿
- [ ] `pnpm validate` 全绿
- [ ] `git diff` 里没有新的 `dependencies`
- [ ] `git diff` 里没有 `progress` / `target` / `streak` / `reminder` / `achievement`
- [ ] 新增的 `kcal` 数值抽查了 2 个
- [ ] `acceptance.yaml` 的 skip 数没有增加

---

## 如果它卡住了

| 症状 | 处理 |
|---|---|
| 反复改同一个测试 | 停下来看是不是文档有歧义，改文档而不是改代码 |
| 想装包解决 | 拒绝。让它自己写，写不出来就问 |
| 说要"重构架构" | 拒绝。v0 的架构已经定死 |
| 把 core 里 import 了 fs | CI 应该拦住；没拦住说明 T0 的 eslint 没配好，回去修 |
| 输出英文文案 | 退回，要求中文 |

---

## 什么时候算 v0 完成

```
pnpm test        → 30 条验收 ≥28 通过
pnpm validate    → 30 条数据全绿
coverage         → ≥70%
npx @meal/cli "鸡胸200g 米饭一碗"  → 输出格式正确
packages/web/dist/index.html       → 断网可用
```

到这里，你就可以**开始自己用它记饭了**。

那才是这个项目真正的第一个里程碑——不是代码写完，是**你自己连续用了 7 天**。
