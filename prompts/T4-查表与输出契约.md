## 要做

### 1. `packages/core/src/lookup/index.ts`

```ts
export interface Resolved {
  grams: number
  kcal: number
  protein: number
  carb: number
  fat: number
}

// grams 的推导优先级：
// 1. qty + unit 是绝对单位（units.yaml 有 grams > 0）→ qty * unit.grams
// 2. qty + unit 是相对单位（碗/盘/拳/份/个）→ qty * dish.portions[unit].grams
// 3. 无 qty 无 unit → dish.portions 的第一项
// 4. 都推不出 → null（标 unresolved）
export function toGrams(seg, match, data): number | null

// 营养按 dish.per = 100g 线性折算
export function nutritionOf(grams: number, dish: Dish): Resolved
```

### 2. `packages/core/src/validate/bounds.ts`

照 `docs/02` §7：

| 检查 | 上界 | 超界处理 |
|---|---|---|
| 一拳米饭 | 260 g | `confidence: 'estimate'`，`grams` 给上界值，`flag: 'over_limit'` |

### 3. `packages/core/src/index.ts`

严格照 `docs/02` §6 的 `MealResult` 契约：

```ts
export function parseMeal(raw: string, data: DataSet): MealResult
```

**confidence 赋值规则：**

| 情况 | confidence |
|---|---|
| 有精确克数、单位是绝对单位、在界内 | `exact` |
| 无克数，走 `portions` 默认份量 | `estimate` |
| 有 `approx: true`（左右/大概） | `estimate` |
| 超物理上界 | `estimate` |
| 匹配不到 dish | `unresolved` |

**total 规则（照 §6）：**

- 全 `exact` → `total.kcal` 有值，`kcalRange: null`
- 有任一 `estimate` → `total.kcal: null`，`kcalRange` 取 `[sum*0.85, sum*1.15]` 取整
- 全 `unresolved` → `total` 全 `null`
