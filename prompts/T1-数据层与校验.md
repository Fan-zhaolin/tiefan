# T1 · 数据层与校验器

先读：`AGENTS.md`、`docs/01-数据模型.md`

## 目标

建出 Dish / Unit / Method 的 schema、类型、数据文件、构建脚本、校验器。

## 要做

### 1. 类型定义（`packages/data/src/types.ts`）

严格照 `docs/01` §2 的字段，`per` 固定字面量 `'100g'`，`source` 用联合类型而非 string：

```ts
export type Source = 'TFDA' | 'USDA' | 'LABEL' | 'MANUAL'
export type Kind = 'dish' | 'ingredient' | 'packaged'
```

### 2. 数据文件

- `packages/data/units.yaml`：照 `docs/01` §3 原样写入 6 个单位
- `packages/data/methods.yaml`：照 `docs/01` §5 原样写入 10 个做法
- `packages/data/dishes/`：**只建 5 个**，作为格式样例：
  - `jixiong.yaml`（鸡胸，ingredient，source: USDA）
  - `mifan.yaml`（米饭，dish，portions 含 碗=150g、拳=140g，source: TFDA）
  - `jidan.yaml`（鸡蛋，ingredient，portions 含 个=50g，source: USDA）
  - `niunai.yaml`（牛奶，ingredient，portions 含 杯=250g，source: TFDA）
  - `fanqiechaodan.yaml`（番茄炒蛋，dish，portions 含 盘=320g，method: jiachangchao，source: TFDA）

> **数据必须来自真实来源。** 如果你不确定某个数值，把这个文件留成 `kcal: null` 并标 `source: MANUAL`，在 `note` 写"待录"。**不要编一个看起来合理的数字。**

### 3. 构建脚本（`packages/data/scripts/build.ts`）

YAML → `packages/data/dist/data.json` + `dist/index.ts`
输出结构对齐 `docs/03` §3 的 `DataSet`：

```ts
export interface DataSet { dishes: Dish[]; units: Unit[]; methods: Method[] }
```

### 4. 校验器（`packages/data/scripts/validate.ts`）

实现 `docs/01` §6 的 **11 条**，每条失败时打印：

```
✗ fanqiechaodan: 规则 1 宏量自洽，偏差 0.23 > 0.15
  kcal=92, 4P+4C+9F=68.3
```

结尾打印 `校验通过：N 个文件`。有任一失败则 `process.exit(1)`。

**必须零运行时依赖**（只用 `node:fs`、`node:path` 和一个 yaml parser 作 devDep）。

### 5. 脚本接线

`packages/data/package.json`：
```json
{
  "scripts": {
    "build": "tsx scripts/build.ts",
    "validate": "tsx scripts/validate.ts"
  }
}
```

## 不要做

- ❌ 不录超过 5 个菜
- ❌ 不实现做法模板的计算（只要结构）
- ❌ 不写解析逻辑

## 验收

```bash
pnpm validate   # 通过，输出「校验通过：5 个文件」
pnpm --filter @meal/data build
cat packages/data/dist/data.json | head   # 结构正确
```

## 反向验证（重要）

手动把 `jixiong.yaml` 的 `kcal` 改成 `9`（明显不自洽），跑 `pnpm validate`，**必须被规则 1 拦住**。确认后改回去。

再把 `mifan.yaml` 的 `portions` 里「拳」改成 `300g`，跑 `pnpm validate`，**必须被规则 10 拦住**（一拳 ≤ 260g）。确认后改回去。
