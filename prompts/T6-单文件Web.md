# T6 · 单文件 Web（采集面）

先读：`AGENTS.md`、`docs/02-解析与交互.md` §8–§11

## 目标

一个 `index.html`，双击可开，手机可加到主屏。**这是唯一的采集入口。**

## 硬约束

- **单个 HTML 文件**，内联所有 JS 和 CSS
- **零外部请求**（不许 CDN、不许 fetch 远程数据）
- **不引入任何框架**（原生 DOM）
- data.json 与 core 代码构建时内联

产物目标：`packages/web/dist/index.html`，< 150KB。

## 要做

### 1. 布局（照 docs/02 §8）

```html
┌──────────────────────────┐
│ [输入框：中午吃了什么…]  │
│──────────────────────────│
│ 12:40  黄焖鸡米饭  约 520│
│ 09:10  两个鸡蛋    约 140│
│──────────────────────────│
│ 今天              约 660 │
│                          │
│      [今天不记]          │
└──────────────────────────┘
```

- 输入框在顶部，固定不滚动
- 时间线按时间倒序（最新在上）
- 底部固定：今日合计 + 「今天不记」

### 2. placeholder 随时段变

| 时段 | 文案 |
|---|---|
| 05–10 | 早饭吃了什么… |
| 10–14 | 中午吃了什么… |
| 14–17 | 下午吃了什么… |
| 17–22 | 晚上吃了什么… |
| 22–05 | 又吃了什么… |

### 3. 记录交互（照 §10）

回车提交 → 结果**原地出现**在时间线顶部 → 输入框清空 → 光标回输入框。

**不要：动画、勾选、震动、绿色高亮、toast。**
唯一变化是行出现 + 合计数字无声更新。

### 4. 降级 UI（照 §11）

解析出 `estimate` 且有 `portions` 可选时，那一行下面展开：

```
22:10  面包
       约 130 – 320
多大的面包？
 [ 一片 ] [ 一个 ] [ 一大个 ]
       就这样
```

- **先出区间，再问**
- 按钮文字来自 `dish.portions[].unit`
- 出口按钮文案必须是 **「就这样」**，不是「跳过」「取消」
- 点选后该行从区间变为点值
- 点击次数 ≤ 1

### 5. 「今天不记」

点击后：什么都不发生。无记录、无提示、无 toast、无确认框。
**只把输入框失焦并收起键盘。**

### 6. 存储

`localStorage`，key 为 `meal:YYYY-MM-DD`，value 为条目数组。
启动时只读今天。

顶部设置区（默认折叠）放一个 `导出` 按钮 → 下载 `meal-backup.json`。

### 7. 禁止清单（照 §13，逐条自查）

- ❌ 进度环 / 达成率 / 百分比对比
- ❌ 红绿配色表达好坏
- ❌ 任何箭头（↑↓）
- ❌ streak / 连续天数
- ❌ 推送、弹窗、引导遮罩
- ❌ 「达标 / 未达标 / 超标」
- ❌ 情绪化文案、emoji

## 不要做

- ❌ 不做第二屏（仪表）
- ❌ 不做设置页（除了导出按钮）
- ❌ 不做深色模式（用 `prefers-color-scheme` 自动即可）
- ❌ 不做 PWA manifest / service worker（v0 不需要）

## 验收

```bash
pnpm --filter @meal/web build
# 产出单个 packages/web/dist/index.html
```

人工检查：

- [ ] 文件里没有 `http://` / `https://` 外链
- [ ] 断网后功能完全正常
- [ ] 手机 Safari 打开 → 添加到主屏 → 可用
- [ ] 输入「鸡胸200g」→ 正确出数
- [ ] 输入「吃了点东西」→ 不报错，提示"没认出是什么"
- [ ] 输入「」→ 不报错
- [ ] 点「今天不记」→ 界面无任何变化

## 文案规范

| 场景 | 文案 |
|---|---|
| 解析不出 | `没认出是什么。原文：xxx` |
| 未命中项 | 原样显示，灰字，不加"失败"字样 |
| 合计（全 exact） | `今天 505` |
| 合计（含 estimate） | `今天 约 505` |
| 无记录 | `今天还没记` |

**不要写「记一笔」「打卡」「今日目标」这类词。**
