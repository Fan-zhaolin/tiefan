# T0 · 脚手架

先读：`AGENTS.md`、`docs/03-架构与边界.md`

## 目标

建出可运行的 monorepo 骨架。**不写任何业务逻辑。**

## 要做

1. `pnpm-workspace.yaml`，workspace 为 `packages/*`
2. 四个包，每个都有 `package.json` + `tsconfig.json`：
   - `packages/core`（`@meal/core`，`"type": "module"`，无 dependencies）
   - `packages/cli`（`@meal/cli`，bin: `meal`）
   - `packages/web`（空，只有一个占位 `index.html`）
   - `packages/data`（`@meal/data`，有 `dist/` 构建产物）
3. 根 `tsconfig.base.json`：`strict: true`、`target: ES2022`、`moduleResolution: bundler`、`noUncheckedIndexedAccess: true`
4. 根 `package.json` 的 scripts：
   ```json
   {
     "build": "pnpm -r build",
     "test": "vitest run",
     "lint": "eslint .",
     "validate": "pnpm --filter @meal/data validate",
     "cli": "pnpm --filter @meal/cli dev --"
   }
   ```
5. `vitest.config.ts`：include `packages/**/*.test.ts`
6. **eslint 边界规则**（`docs/03` §2 原文照抄）：
   - `packages/core` 下 `no-restricted-imports`: `node:*`、`fs`、`path`、`os`、`child_process`
   - `no-restricted-globals`: `window`、`document`、`localStorage`、`fetch`
7. 三个 CI workflow，用 `paths:` 隔离（`docs/03` §8）
8. `.gitignore`：`node_modules`、`dist`、`.DS_Store`

## 不要做

- ❌ 不装任何运行时依赖（devDependencies 只允许：typescript、vitest、eslint、tsup、esbuild、yaml）
- ❌ 不写解析逻辑
- ❌ 不写任何数据
- ❌ 不引入 React / Vite / 任何前端框架

## 验收

```bash
pnpm install
pnpm lint        # 通过
pnpm test        # 通过（此时 0 个测试也应通过）
```

## 额外自检

在 `packages/core/src/index.ts` 里故意写一行 `import fs from 'node:fs'`，跑 `pnpm lint`，**必须报错**。确认后删掉。
