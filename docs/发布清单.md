# 发布清单

> 每次公开发布前逐条打勾。**打不了勾就不发。**

## 首次公开前（只做一次）

- [ ] 仓库不含 `node_modules` / `dist` / 本地配置
- [ ] 每份 `dishes/*.yaml` 的 `source` 都是合法枚举（TFDA / USDA / LABEL / MANUAL）
- [ ] 没有「看起来合理但查不到来源」的数值；待录入项必须在 `note` 写明
- [ ] 三份许可证齐全：`LICENSE`（AGPL-3.0）、`docs/LICENSE`（CC-BY-SA 4.0）、`packages/data/LICENSE`（ODbL 1.0）
- [ ] README 的 License 段与三份文件一致
- [ ] README 里的 `git clone` 是真实地址，不是占位符
- [ ] **陌生人测试**：干净目录下 `git clone` → `pnpm install` → `pnpm build` → `pnpm test` 全绿
- [ ] 已读 `CONTRIBUTING.md` 的贡献者授权条款，确认它存在

## 每次改动后

- [ ] `pnpm test` 全绿（1 个 expected fail + 若干 skip 属正常，新增 skip 需说明理由）
- [ ] `pnpm validate` 通过
- [ ] Web 产物仍是单文件，且 `grep -n 'http'` 无外链
- [ ] 红线自查：无进度环 / 达成率 / 红绿配色 / 箭头 / streak / 「达标·超标」

## 每次部署前

- [ ] 桌面打开一次：输入「鸡胸200g 米饭一碗」能出区间
- [ ] 手机打开一次，五项：能记 / 能出区间 / 未认出有提示 / 「今天不记」无反应 / 刷新后记录还在
- [ ] 国内可访问性：**打开超过 3 秒就换托管**，别修
- [ ] 迁移托管后，同步更新 README 里的线上地址

## 版本

| 层 | 版本 | 频率 |
|---|---|---|
| 数据 | `data-vYYYY.MM` | 每月 |
| 实现 | `vX.Y.Z` | 有实质改动 |
| 规格 | `spec-vX.Y` | 一年 1–2 次 |

## 顺带约定

- 分享截图时，输入里**避免用「盒 / 瓶 / 罐」**——v0 不认包装单位，会显示「合计不可用」。
  这不是 bug，是「不猜」的既定行为。
